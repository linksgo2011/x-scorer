# 🚀 Viral Content Scorer - 病毒内容评分器

基于传播学理论的多维度内容传播潜力评估工具，帮助创作者科学分析和优化社交媒体内容的传播效果。

## ✨ 核心功能

### 📊 多模型支持
- **影响力模型** (influence) - 基于罗伯特·西奥迪尼《影响力》六大原则
- **疯传模型** (contagious) - 基于乔纳·伯杰《疯传》STEPPS理论
- **病毒评分模型** (viral-scoring) - 基于实战经验的内容传播评估
- **自定义模型** - 支持加载用户自定义的传播学模型

### 🎯 智能分析
- **多维度评分**: 情绪共鸣、热点关联、故事性、互动钩子等维度
- **关键词匹配**: 基于传播学理论的关键词库分析
- **AI智能评分**: 可选的AI评分增强分析准确性
- **优化建议**: 针对每个维度提供具体的改进建议

### 📄 灵活输入
- **文件分析**: 支持Markdown、文本文件分析
- **测试模式**: 内置测试内容快速验证模型
- **自定义模型**: 支持JSON和Markdown格式的模型文件

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

### 基础使用

#### 1. 查看可用模型
```bash
node app.js -l
# 或
node app.js --list
```

#### 2. 使用默认模型分析内容
```bash
# 分析Markdown文件
node app.js sample-content.md

# 使用特定模型
node app.js sample-content.md -m influence
```

#### 3. 测试模式
```bash
# 测试内置内容
node app.js -t

# 使用特定模型测试
node app.js -t -m contagious
```

## 📖 命令详解

### 基本命令格式
```bash
node app.js [文件路径] [选项]
```

### 可用选项

| 选项 | 说明 | 示例 |
|------|------|------|
| `-l, --list` | 列出所有可用模型 | `node app.js -l` |
| `-t, --test` | 使用测试内容 | `node app.js -t` |
| `-m, --model <name>` | 指定分析模型 | `node app.js -m influence` |
| `--load <file> <name>` | 加载自定义模型 | `node app.js --load my-model.json my-model` |
| `--no-ai` | 禁用AI评分（仅关键词匹配） | `node app.js --no-ai` |
| `-h, --help` | 显示帮助信息 | `node app.js -h` |

### 高级用法

#### 加载自定义模型
```bash
# 从JSON文件加载
node app.js --load models/my-model.json my-custom-model

# 从Markdown文件加载  
node app.js --load "我的模型.md" custom-model
```

#### 组合使用
```bash
# 加载模型并立即测试
node app.js --load new-model.json new-model -t

# 使用自定义模型分析文件，禁用AI评分
node app.js content.md -m my-model --no-ai
```

## 📊 内置模型详解

### 🔥 影响力模型 (influence)
基于罗伯特·西奥迪尼《影响力》理论，包含6个维度：
- **互惠原理** - 先给予后索取的策略
- **承诺一致** - 让人们做出承诺并保持一致
- **社会认同** - 利用从众心理影响决策
- **喜好原理** - 通过相似性和赞美建立好感
- **权威效应** - 利用专家和权威的影响力
- **稀缺效应** - 通过稀缺性增加价值感知

### 📈 疯传模型 (contagious) 
基于乔纳·伯杰《疯传》STEPPS理论，包含6个维度：
- **社交货币** - 让分享者显得更有价值
- **诱因触发** - 创造易于记忆和传播的联系
- **情绪驱动** - 激发高唤醒情绪促进传播
- **公开可见** - 提高内容的可见性和模仿性
- **实用价值** - 提供有用的信息和帮助
- **故事包装** - 用故事形式传递信息

### 🎯 病毒评分模型 (viral-scoring)
基于实战经验总结的5维度评估模型：
- **情绪共鸣度** (30%) - 激发强烈情绪反应
- **热点关联** (25%) - 连接当前热门话题
- **故事性** (20%) - 具有完整的故事结构
- **互动钩子** (15%) - 包含提问和互动引导
- **通俗度** (10%) - 使用通俗易懂的语言

## 🎨 评分标准

### 等级划分
| 分数范围 | 等级 | 传播潜力 | 建议 |
|----------|------|----------|------|
| 80-100分 | 🔥爆款潜力 | 病毒式传播 | 立即发布，准备承接流量 |
| 60-79分 | ⭐高互动潜力 | 大量讨论转发 | 可以发布，继续优化细节 |
| 40-59分 | 👍中等互动 | 一般互动 | 需要优化，重点改进低分项 |
| 0-39分 | ⚠️低互动风险 | 几乎无互动 | 大幅修改，重新规划内容 |

### 评分方式
- **关键词匹配**: 基于理论模型关键词库的基础评分
- **AI智能增强**: 可选的AI评分提供更精准的分析
- **维度权重**: 不同维度根据重要性有不同的权重系数

```json

```

## 💡 使用技巧

### 内容创作建议
1. **情绪共鸣**: 使用强烈的情绪词汇，激发读者情感反应
2. **热点关联**: 结合当前热门话题和趋势
3. **故事结构**: 采用完整的故事叙述结构
4. **互动引导**: 结尾加入提问或讨论邀请
5. **通俗易懂**: 避免过度专业化，使用生活化语言

### 模型选择
- **影响力模型**: 适合销售、营销类内容分析
- **疯传模型**: 适合社交媒体、病毒内容分析  
- **病毒评分模型**: 适合一般内容传播潜力评估
- **自定义模型**: 根据特定需求创建专属评估标准
